# FireWall Rules для Cinema Booking System

## Сетевая топология

| Зона | Подсеть | Компоненты |
|------|---------|------------|
| Public Zone | 10.10.1.0/28 | API Gateway (future) |
| Internal Zone | 10.10.2.0/28 | booking-service |
| Data Zone | 10.10.3.0/28 | postgres, redis, rabbitmq |

## Правила FireWall

### ✅ ЯВНОЕ РАЗРЕШЕНИЕ (Allow)

| Источник | Направление | Протокол | Порт | Назначение | Обоснование |
|----------|-------------|----------|------|------------|-------------|
| booking-service (10.10.2.x) | → | TCP | 5432 | postgres (10.10.3.x) | Сервис читает/пишет в БД |
| booking-service (10.10.2.x) | → | TCP | 6379 | redis (10.10.3.x) | Сервис использует кэш |
| booking-service (10.10.2.x) | → | TCP | 5672 | rabbitmq (10.10.3.x) | Сервис публикует события |
| External (Internet) | → | TCP | 8000 | booking-service (10.10.2.x) | Пользовательский доступ к API |

### ❌ ЯВНЫЙ ЗАПРЕТ (Deny)

| Источник | Направление | Протокол | Порт | Назначение | Обоснование |
|----------|-------------|----------|------|------------|-------------|
| postgres (10.10.3.x) | → | ANY | ANY | booking-service (10.10.2.x) | БД не должна инициировать соединения |
| redis (10.10.3.x) | → | ANY | ANY | booking-service (10.10.2.x) | Кэш не должен инициировать соединения |
| rabbitmq (10.10.3.x) | → | ANY | ANY | booking-service (10.10.2.x) | Брокер только принимает подключения |
| postgres (10.10.3.x) | → | ANY | ANY | redis (10.10.3.x) | Горизонтальное общение в Data зоне запрещено |
| redis (10.10.3.x) | → | ANY | ANY | rabbitmq (10.10.3.x) | Горизонтальное общение в Data зоне запрещено |

## Принцип минимальности доступа

- Сервисы в Data Zone (postgres, redis, rabbitmq) **не имеют доступа** к Internal Zone
- Сервисы в Data Zone **не могут общаться друг с другом** (изоляция компонентов)
- Только booking-service имеет право инициировать соединения к Data Zone
- Внешний трафик может достигать только booking-service через порт 8000
